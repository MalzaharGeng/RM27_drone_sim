# Drone-Harrier：RM 小无人机硬件配置

硬件由用户于 2026-11-23 确认。型号及对应的 Gazebo visual 或 sensor 名称见 [hardware.json](hardware.json)。本模型在原 Drone-Harrier 上补齐已确认的硬件表示：

| 部件 | 实机选型 | 仿真表示 |
|---|---|---|
| 前置双目 | DECXIN 成品双目 | 沿用原双目、话题和外参 |
| 飞控与电调 | 微空 MicoAir 743 V2 AIO 35A | 原 CAD 上层约 40 毫米板件作为外形代理 |
| 机载计算 | 香橙派 CM5，RK3588S，4 GB RAM + 32 GB 存储 | 原 CAD 下层约 55×40 毫米板件作为外形代理 |
| 动力 | 四台 T-MOTOR 1204 6500 KV、1816 桨 | 原 CAD 四组电机和桨的独立外观，保留原约 45 毫米桨面 |

沿用原 Gabel CAD 和机身碰撞体。分件网格来自同一份 CAD，只重新分配部件与材质，不增删三角面。板件的位置和外观用于仿真展示；实机安装外参、板卡装配与零件厂家 CAD 尚未核对。桨外观不连到较远的 X500 虚拟转子位置。

Gazebo 模型资源为 `drone_harrier`，场景实体名为 `Drone-Harrier`。PX4 SITL 仍用 `gz_x500_mono_cam` 的机型参数接入场景中的 Harrier。前视双目、IMU 与原碰撞不变；默认从 H 台面出生。CM5 算力、板级电调、实机质量/惯量与推力没有被模拟。本版是硬件装配和视觉基线；如果用于真机动力学对比，需要称重、测重心和旋翼轴位置，并测实际带桨推力和响应，再另外校准。2026-11-23 后续更新：已接入 OV9281 下视灰度相机（1280×800，目标 120 Hz）并在 H 平台配置台面 Tag 0 和立牌 Tag 1。原 DECXIN 前视双目不变；OV9281 实物装机和可见光通信仍待验证。
