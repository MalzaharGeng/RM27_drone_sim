## 仓库内容与运行入口

- `scripts/`：生产飞手、PX4/BT 交接、严格 health、独立真值监督、记录器及评估器。FIX20 飞手与对应原实物同字节。
- `ros2/rm27_slam/`：从实际 ROS 工作空间纳入的双目/IMU 节点及真值对照节点。真值对照不能作为真实 VIO 精度验收。
- `rm27_sim/worlds/rm27_wide_world.sdf` 与模型 `rm27_wide_floor`：独立扩大场景。原场地另行保留；视觉纹理补充不构成原场地可靠性验收。
- `wb_handoff_20261114/workpkg_20261115/`：FIX18 生命周期管理、FIX19 记录环境、FIX20 测试及冻结记录，仅纳入运行和复核所需文件。
- `tests/test_excite_height_production.py`：仓库相对路径版生产决策回放，使用截取的历史 EXCITE 输入。原测试脚本在实验目录保留。

实验环境保留原始绝对路径（`/home/gengyinghao/drone_sim`、`px4_ws_201` 和 `ORB_SLAM3`），以便核对历史源码。更换环境前需检查路径配置，跨机器启动尚未验证。注入计时和测量问题本轮未改。

构建 ROS 适配器需先编译 ORB_SLAM3，构建匹配 PX4 1.17 的 px4_msgs，再把本仓库 `ros2/rm27_slam` 链接/复制到工作空间 src 并运行 `colcon build --packages-select rm27_slam`。其 CMake 默认读取 `$HOME/ORB_SLAM3/build`，ROS Lyrical 与 Pangolin 依赖见包文件。重建二进制应另行编号并记录哈希，与历史 `stereo_inertial_sim_node.fix15` 区分。

历史正常轮 launcher 是 `wb_handoff_20261114/workpkg_20261115/newpkg_fix19/recordenv/launch_run_wide_fix19.sh`；它依赖冻结节点所在的 `bin/`。历史二进制和大日志存放在本地，完整复现冻结飞行还需对应实物。`run_vio_interruption_fix19.sh --preflight` 会运行替身自检，省略该参数会启动真实仿真，只在另获明确飞行授权时使用。
